Schema Reference

      

        POST a { "query": "..." } JSON body to /graphql (standard
        GraphQL-over-HTTP). CORS is open, so it's queryable from other origins too.
      

      

        This API is intentionally scoped to personal review data only. For full anime metadata
        (synopses, episode counts, community scores, and more), pair it with
        AniList's own public GraphQL API
        — a review's anilistId, when set, is the id to look it up by.
      


      
Query

      
    
        
  • seasons: [SeasonSummary!]! — every season in the index (id + name only)
    • 
        
  • currentSeason: Season — the in-progress season, with full review data
    • 
        
  • season(id: ID!): Season — a specific season's full data, by id
    • 
        
  • anilistQuery(titles: [String!], anilistIds: [Int!]): String! — recommendations, step 1: the AniList query to run for up to 25 shows someone liked
    • 
        
  • recommend(anilistResponse: String!, count: Int = 2): Recommendations! — recommendations, step 2: picks from these reviews, from AniList's result
    • 
      


      
Recommendations

      
    
        
  • liked: [LikedShow!]! — how each liked show was matched on AniList: input, found, anilistId, title
    • 
        
  • profile: [TasteFeature!]! — the genres and tags they share (name, kind, weight 0–1), strongest first
    • 
        
  • picks: [Recommendation!]! — the closest 4+ reviews, chosen so they don't all overlap each other
    • 
        
  • hiddenGem: Recommendation — the least popular remaining 5 that still shares something
    • 
      


      
Recommendation

      
    
        
  • show: Show!
    • 
        
  • score: Float! — closeness to the profile, scaled by the current rating, 0–1
    • 
        
  • popularity: Int — AniList members with it on their list
    • 
        
  • sharedGenres: [String!]!, sharedTags: [String!]! — what got it picked
    • 
      


      
Season

      
    
        
  • id: ID!
    • 
        
  • name: String!
    • 
        
  • lineup: Boolean! — true for a season reviewed live (an id like spring-2026), false for a shelf like the Backlog
    • 
        
  • shows: [Show!]!
    • 
        
  • toReview: [String!]!
    • 
        
  • notReviewing: [String!]!
    • 
        
  • toReviewShows: [ToReviewShow!]! — the shows still to review, with their optional streaming and premiere info
    • 
        
  • notReviewingShows: [NotReviewingShow!]! — the shows not being reviewed, with their optional reason and streaming info
    • 
      


      
ToReviewShow

      
    
        
  • title: String!
    • 
        
  • streaming: [String!]! — service keys, empty when none are recorded
    • 
        
  • premieres: String — optional, the day the first episode premieres, YYYY-MM-DD
    • 
        
  • availableNow: Boolean! — true when the show is already out
    • 
        
  • crunchyrollUrl, hidiveUrl, netflixUrl, huluUrl, primeUrl, youtubeUrl: String — optional direct links
    • 
      


      
NotReviewingShow

      
    
        
  • title: String!
    • 
        
  • reason: String — optional short reason it isn't being reviewed
    • 
        
  • streaming: [String!]! — service keys, empty when none are recorded
    • 
        
  • crunchyrollUrl, hidiveUrl, netflixUrl, huluUrl, primeUrl, youtubeUrl: String — optional direct links
    • 
      


      
Show

      
    
        
  • titleEN: String!
    • 
        
  • titleJP: String
    • 
        
  • aired: Aired — when it first aired, from AniList
    • 
        
  • reviews: [Review!]! — every review of it, oldest first
    • 
        
  • ratingNumber: Float, ratingText: String — the current rating: the latest review's
    • 
        
  • op: Boolean, ed: Boolean — true when an opening/ending was liked; the numbers are in opNumbers/edNumbers
    • 
        
  • watched: Watched — when the show was watched, null when not recorded
    • 
        
  • season: ID! — id of the season file it's listed in
    • 
        
  • seasonName: String! — display name of that season
    • 
        
  • anilistId: Int — optional AniList media id, when set
    • 
      


      
Review

      
    
        
  • stage: String! — first (a first impression, after episode 1), revisit, final (the verdict once it's finished), or review (a first review with no episode-1 basis)
    • 
        
  • episodes: Int — how many episodes it was based on
    • 
        
  • final: Boolean
    • 
        
  • ratingNumber: Float
    • 
        
  • ratingText: String — the review's own label, or its tier's default
    • 
        
  • text: String
    • 
        
  • dateReviewed: String
    • 
      


      
Aired

      
    
        
  • season: String — winter, spring, summer or fall; null when AniList has only a year
    • 
        
  • year: Int!
    • 
      


      
Watched

      
    
        
  • from: String! — the day the first episode was watched, YYYY-MM-DD
    • 
        
  • to: String — the day the last one was
    • 
        
  • season: Int, episode: Float — the last episode reached, for a show that wasn't finished
    • 
        
  • finished: Boolean — true when the whole thing was watched
