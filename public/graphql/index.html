Schema Reference

      

        POST a { "query": "..." } JSON body to /graphql (standard
        GraphQL-over-HTTP). CORS is open, so it's queryable from other origins too.
      


      
Query

      
    
        
  • seasons: [SeasonSummary!]! — every season in the manifest (id + name only)
    • 
        
  • currentSeason: Season — the in-progress season, with full review data
    • 
        
  • season(id: ID!): Season — a specific season's full data, by id
    • 
      


      
Season

      
    
        
  • id: ID!
    • 
        
  • name: String!
    • 
        
  • number: Int — optional MAL season id
    • 
        
  • reviewed: [Review!]!
    • 
        
  • pending: [String!]!
    • 
        
  • skipped: [String!]!
    • 
      


      
Review

    •

    • 
        
  • review: String
    • 
        
  • dateReviewed: String
    • 
        
  • fullReview: SubReview — full-series re-review, once a "Finish Ep"-rated show is actually finished
    • 
        
  • op: SubReview — opening callout

  • ed: SubReview — ending callout
    •

    •
