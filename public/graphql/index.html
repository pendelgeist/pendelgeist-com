Seasonal Anime GraphQL API

Query the same season data that powers VQAR

Try It


    


    

      
Schema Reference

      

        POST a { "query": "..." } JSON body to /graphql (standard
        GraphQL-over-HTTP). CORS is open, so it's queryable from other origins too.
      


      
Query

      
    
        
  • seasons: [SeasonSummary!]! — every season in the manifest (id + name only)
    • 
        
  • currentSeason: Season — the in-progress season, with full review data
    • 
        
  • season(id: ID!): Season — a specific season's full data, by id
    • 
      


      
Season

      
    
        
  • id: ID!, name: String!, number: Int
    • 
        
  • reviewed: [Review!]!, pending: [String!]!, skipped: [String!]!
    • 
      


      
Review

      
    
        
  • titleEN: String!, titleJP: String
    • 
        
  • ratingNumber: Float, ratingText: String, review: String, dateReviewed: String
    • 
        
  • fullReview / op / ed: SubReview — optional follow-up notes
    • 
        
  • season: ID!, seasonName: String!
    • 
      


      
SubReview

      
    
        
  • ratingNumber: Float, ratingText: String, review: String, dateReviewed: String
